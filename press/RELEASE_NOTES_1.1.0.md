# TagoPitch 1.1.0

TagoPitch now runs in Pro Tools on macOS.

## New

- **Pro Tools (AAX) on macOS.** TagoPitch now comes as an AAX plugin for Pro
  Tools, mono and stereo, signed for Pro Tools. Windows AAX follows later.

## Install

- **macOS 11+:** run the `.pkg` and pick the formats you want (AU + VST3 + AAX,
  notarized).
- **Windows:** unzip and drop the `.vst3` into your VST3 folder.

Settings and presets from earlier versions carry over unchanged.
